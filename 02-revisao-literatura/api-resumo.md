Resumo sobre API.

"bom uma API, é usada para comunicar 2 sistemas. por exemplo, eu quero fazer uma plataforma de filmes, mas pra mim adicionas 1 por 1 de cada filme que existe vai ser muito trabalhoso, e demorado, entao eu uso a API de um sistema que ja tem os filmes. entao API serve com um mensageiro, que leva o meu pedido para outro sistema, e outro sistema me manda uma resposta atraves de uma API. resumindo, serve como um meio de comunicação entre 2 sistemas distintos."
"API é uma interface que permite que diferentes sistemas ou aplicações se comuniquem e troquem dados ou funcionalidades de maneira padronizada."
