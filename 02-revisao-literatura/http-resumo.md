Resumo de HTTP

Hypertext Transfer Protocol

A api web usa normalmente o HTTP para enviar informações e receber.
sistema -> http -> api -> outro sistema

quando o sistema que uma informação de outro sistema ele usa o protocolo http.
existe diferentes tipos de requisição. GET, POST, PUT e DELETE. o que vamos usar é GET, e POST

"usaria POST, porque POST envia as informações de algoritmo que o aluno fizer, é atraves dele, que a IA vai receber o algoritmo para a analise, ja o GET vai devolver uma informação, para o aluno, ou para a interface do aluno."

GET  → "Quero buscar isso."
POST → "Quero enviar isso."
