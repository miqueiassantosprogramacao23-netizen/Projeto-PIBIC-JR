Resumo de REST

REST é uma maneira de organizar como uma API trabalha com seus recursos usando requisições.

GET → consultar/obter informações.
POST → enviar dados para criar/processar algo.
API → permite a comunicação entre sistemas.
HTTP → protocolo usado nessa comunicação.
REST → uma forma de organizar essa API usando recursos e operações HTTP.

API = o atendente
HTTP = o meio usado para fazer o pedido
JSON = o papel onde está escrito o pedido
REST = as regras de organização dos pedidos

REST significa Representational State Transfer.
REST não é um protocolo como HTTP. É um estilo arquitetural para organizar a comunicação entre sistemas.
REST foi definido por Roy Fielding em sua tese de doutorado, publicada em 2000.

Recurso

HTTP → é o protocolo de comunicação.
REST → é uma forma de estruturar essa comunicação.
API → é a interface que permite que os sistemas conversem.
JSON → é um dos formatos que podemos utilizar para transportar os dados.
